# Map: Hash Table Implementation

## Overview
Implemented a custom hash table in C++ supporting efficient key-value storage and retrieval operations.

## Features
- Insert key-value pairs
- Update existing values
- Remove entries
- Retrieve values by key
- Efficient lookup operations

## Concepts Demonstrated
- Hash Tables
- Collision Handling
- Object-Oriented Programming
- Dynamic Memory Management
- Algorithm Design and Analysis
- Unit Testing

## Technologies
- C++
- Xcode

## Repository Structure
- `Map.h` – Class declarations and public interface
- `Map.cpp` – Hash table implementation
- `testMap.cpp` – Unit tests and validation
- `main.cpp` – Example usage and testing
